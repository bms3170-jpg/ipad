# Personal System — Complete 20 Theme Worlds v5.2

사용자가 최종 확정한 20개 이미지를 기준으로, 각 디자인을 홈부터 설정까지 이어지는 화면 시스템으로 구성합니다.

## 핵심 수정
- Brutalist OS를 참고 이미지와 동일한 구도의 전용 홈으로 재구성
- 시계·날씨·음악·할 일·달력·메모·집중·일정·메모리 스트립을 이미지 속 위치에 직접 배치
- Brutalist에서는 기존의 공통 대형 위젯 그리드를 사용하지 않음
- TODAY부터 SETTINGS까지 모든 페이지에 Brutalist 전용 구조·색·컨트롤 적용
- 사이드바, Dock, 팝업, 입력창과 상태 표시도 전 페이지에서 동일한 디자인 언어 유지
- 20개 테마마다 제목·본문·시간 숫자 폰트 조합을 각각 다르게 설정
- 사진에서 확인한 파스텔 도시, 석양 사이버, 네온 도시, 수중, 숲, 우주, 벚꽃, 애니, 우주선, 카페 디자인 추가
- 사진에 없던 임시 테마는 테마 선택 목록에서 제거
- 2번 Retro Terminal 홈을 참고 이미지와 같은 전용 command-center 배치로 교체
- 반복되던 임시 미리보기 이미지를 테마별 고유 미리보기로 교체
- 3번 Blueprint CAD 홈을 참고 이미지와 같은 전용 설계도 배치로 교체
- 20개 초안에서 UI가 제거된 배경 전용 이미지를 별도로 제작해 적용
- 완성 초안 스크린샷을 배경으로 쓰지 않아 가짜 글자와 실제 위젯이 겹치지 않음
- 각 테마의 시계·날씨·할 일·일정·음악·집중 위젯은 실제 데이터로 작동
- 테마마다 서로 다른 위젯 위치, 패널 재질, 모서리, 글꼴 및 장식 사용
- 상단 공통 HOME 툴바와 별도 공통 장식을 제거해 초안 구도 확보
- 가로 화면은 4:3 참고 이미지 전체가 잘리지 않도록 표시
- 실제 위젯은 테마별 사진의 패널 영역을 따르는 12열 레이아웃 유지
- 위젯·사이드바·Dock에 배경과 어울리는 반투명 재질 적용
- 기존 Task / Weather / Focus / Music / Calendar 데이터 기능 유지
- Theme Lab의 20개 미리보기와 테마 선택 기능 유지
- 기존 Vite 타입 오류 및 업데이트 새로고침 오류 수정
- 20개 전용 홈 화면과 Today부터 Settings까지 하나의 최종 프로젝트로 통합
- 페이지와 테마를 필요할 때만 불러오는 지연 로딩으로 초기 실행 속도 개선
- 테마 전환 중 전용 로딩 화면을 표시해 끊김을 최소화
- 원본 배경과 미리보기 이미지는 화질 손실 없이 유지
- 20개 화면의 글자·아이콘·도형 정렬과 긴 문장 잘림 처리 보정
- 밝고 어두운 배경에서 흐려지던 글자의 대비와 숫자 정렬 개선
- 테마 수 표기를 20개로 수정하고 적용 즉시 홈 이동 및 수동 선택 유지
- 예전 삭제 테마가 저장되어 있어도 정상 기본 테마로 자동 복구
- 16:9 모니터에서도 원본 아이패드 4:3 좌표계와 도형 비율을 유지
- 원형 타이머·노브·달력 칸·패널이 가로로 늘어나는 현상 수정
- 남는 화면 영역은 테마 바탕색으로 채워 원본 UI가 잘리거나 왜곡되지 않도록 개선

## 실행
```bash
npm install
npm run dev
```

THEME LAB에서 테마를 적용한 뒤 HOME으로 돌아와 배경과 배치를 확인해 주세요.
